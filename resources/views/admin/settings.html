Email sending Not set up

Sends sign-up codes, password reset codes and download links, using your free EmailJS account.

How to set this up
  1. Create a free account at emailjs.com and add a Gmail service. Copy the Service ID.
  2. Copy your Public Key from Account → General.
  3. Create three templates (sign-up code, password reset, purchase). Set "To Email" to {{to_email}}. The README in your site files has the exact text.
  4. Paste the IDs here, save, then send a test email.
